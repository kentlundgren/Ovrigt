Det här är inte ett officiellt Anthropic- eller Claude-verktyg. Bilden analyseras i din egen webbläsare med OCR (teckenigenkänning) och skickas aldrig till någon server — inget sparas, ingenstans. OCR-avläsningen kan bli fel; kontrollera alltid fälten innan du analyserar.

Kärnfrågan

Ladda upp en bild eller fyll i siffrorna nedan

Ladda upp en skärmdump av Inställningar → Usage (en enda bild räcker — session, vecka och usage credits visas där tillsammans).

Det här är värdena verktyget läser av:
  • Current session — din session-andel (%)
  • All models (under Weekly limits) — din vecko-andel (%)
  • Boost-notisen (om den visas) — tillfällig gränshöjning och slutdatum
  • € spent / €-gräns — usage credits denna cykel
  • Resets [datum] — när vecko- eller usage credits-cykeln återställs

{ } GitHub

Hur den här sidan är byggd

Ingen backend, ingen databas — all bearbetning sker i din egen webbläsare, publicerad via GitHub Pages.

OCR helt i webbläsaren

Tesseract.js (WebAssembly) läser av bilden lokalt hos dig. Ingen bild skickas någonsin till en server.

Bilden sparas aldrig

URL.createObjectURL() visar förhandsgranskningen, revokeObjectURL() tar bort referensen så snart OCR:en är klar — lyckad eller inte.

Varför ingen AI-bildanalys

En publik sida kan inte skydda en API-nyckel i klientkod, så en riktig AI-bildläsning hade krävt en egen backend. Se PRD_publik_variant.md för resonemanget — Firebase noterad som en möjlig, medveten framtida väg, inte del av den här leveransen.

Delad beräkningslogik

Formlerna (boost-omräkning, takt-jämförelse, statusgränser) ligger i js/berakning.js och delas med Kents eget verktyg — en ändring görs bara på ett ställe.

Fältmappning, inte magi

Regex-baserad textmatchning (nyckelord + närmaste värde), inte en språkmodell. Kan bli fel — därför är alla fält alltid redigerbara, och inget beräknas förrän du trycker Analysera.
