# Strozzapreti — Prästdödaren

## Om denna rätt

Strozzapreti är en handgjord italiensk pastaform från Emilia-Romagna. Namnet betyder "stryp prästen" — en folkleg berättar att präterna älskade denna pastan så mycket att de åt den med sådan entusiasm att de nästan strypte sig.

### Huvudingredienser
- 400 g strozzapreti pasta
- Italiensk tomatsås (vitlök, lök, sardeller, tomater, vitt vin)
- Parmesan och basilika för garnering
