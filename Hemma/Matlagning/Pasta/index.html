🍝 Italienska Pastarätter med Historia

En samling klassiska italienska pastarätter kopplade till deras fascinerande historier och autentiska recept

Klicka på en pastarätt för att läsa mer historia och se det fullständiga receptet.

Strozzapreti

Prästdödaren — En rustik pastarätt från Emilia-Romagna med en legend om hungrande präster som åt denna pasta med så stort entusiasm att de nästan skulle strypas.

Spaghetti alla Carbonara

Charcoal Maker's Pasta — En romersk klassiker från mitten av 1900-talet. Namnet kan komma från kolarbetare, eller från Amerikaanse soldater under världskriget.

Penne all'Arrabbiata

The Angry One — En "arg" pastarätt från Rom, född ur fattig italiensk kökskultur i 1950-60-talen. Det namnet säger allting: het, passionerad, intensiv.

{ } GitHub

Hur den här sidan är byggd

Ingen extern ram eller byggtool — ren HTML, CSS och JavaScript, publicerad via GitHub Pages. Ingen inloggning, inget konto krävs.

Statisk receptsamling

Ingen server, ingen databas. Varje pastarätt är en egen HTML-fil i en egen undermapp under Pasta/.

Delad CSS

All styling ligger i en enda fil, css/style.css, med CSS-variabler i :root för enkelt temabyte mellan recepten.

Print-optimerad per recept

Varje receptsida har egna @media print-regler så hela receptet (bild, kort historia, ingredienser, instruktioner, källor) får plats på en enda A4-sida.
